October 9, 2026. Current MODEL remains v2.2. The board shows a separate five-category candidate on 51 upcoming games. No started model or grading baseline was changed.

Added national rank inputs: passing offense, rushing offense, pass defense, run defense, and turnover margin. Ranks are computed from ESPN boxscores across the season-specific FBS population, not official NCAA rankings. Offense uses yards/game (higher better), defense uses allowed yards/game (lower better), turnover margin is (takeaways - giveaways)/game (higher better). Ties share the minimum rank. Current ranks include 138 teams through Week 5. The original model already used raw pass/run yardage; relative rank and net turnovers are new.

Decision: not adopted

Validation margin MAE chose pass-defense-only, not the five-category bundle. Its 2025 paired improvement interval crosses zero. Picking the five-category bundle only after seeing its stronger 2025 result would be selection on the test. The requested bundle is shown as a labeled candidate, not the current model. Adding scoring and total-yardage ranks as well (all nine) hurt validation relative to v2.2, so those extra features are not selected.

Pass defense and rushing offense helped validation margin MAE slightly. Run defense, passing offense, and turnover margin individually did not. The five-category bundle helped validation winner accuracy (68.1% to 69.6%) and historical 2025 MAE (12.87 to 12.62), but that is not enough to bypass the selection rule.

Forward 2026 replay and limits

On 114 matched previously frozen Week 4-5 games: frozen v2.2 MAE 13.14 / winners 72.8%; pass-defense-only 13.39 / 70.2%; five-category candidate 13.09 / 74.6%. Candidates were generated retrospectively, never frozen before these games; this is not an untouched prospective test. Rank features themselves use only prior dates. Missing QB-stat fallback uses prior-season means, same as existing scorer. The current reference inherited earlier roster/feature-selection limitations, and 2025 had already been examined in previous builds. The new comparisons do not erase those limits.

Injuries, weekly news, and weather are not converted to point changes by this rank variant. No market-beating or betting recommendation claim is made.
