# Injury-adjusted experiment, Oct 7, 2026

Requested by Garrett after the historical injury test did not pass deployment. The separate `injury_adjustments.json` displays an experimental spread and player/TD availability line next to each frozen baseline. No book feature, pick or approval is introduced. Baselines and model_tracking.json stay unchanged for grading.

Historical exploratory train: 2020-22 residual Ridge(alpha=10) around deployed margin-Elo/totals. Selection: 2023-24. 2025 is already seen and only diagnostic. Three fixed feature sets: QB, position groups, practice-plus-status groups. Best margin variant reduced selection MAE 10.23 to 10.09 and seen-2025 MAE 10.23 to 10.07; descriptive game-bootstrap intervals include zero. Totals worsened, so no adjusted total is displayed. Separate same-window intercept baseline is also reported. No significance claim after model selection.

Current input snapshots: nflverse rosters, weekly injury reports and snaps fetched Oct 7; Sleeper IR list and latest 18 independently checked availability rows already on the site. R01/R48 denote injured reserve; retired and PUP are not silently called IR. Latest per-player roster row is used, including people whose roster row last changed before Week 5. News conflicts remain conflicts. Wednesday DNP is a practice feature, not Out. Dataset Week 5 reports currently cover only DAL/TB, so the news overlay is explicitly partial. Provider-wide IR inventory is not a 32-team transaction audit.

Spread: use fitted practice-plus-status feature coefficients; adjust relative to a no-injury row, so no new residual intercept is silently added. Current-season prior snaps are preferred; previous-season snapshots may be used if no 2026 snaps exist, including prior-team players. Missing snap weights are listed and have zero numerical contribution, not a claim of no injury impact. Long-term absences can already be in the score-only baseline, so this full-absence experiment can double-count them.

Player props and TDs: confirmed IR/Out means zero expected participation, while original baseline remains visible. This is not a book void/settlement probability. DNP/uncertain participation displays pending, not an invented play probability. Healthy/unflagged players retain baseline values with explicit note that teammate/backup opportunity redistribution is not modeled. No arbitrary uplift of backups, receiver downgrades after QB absence, or transfer of removed TD probability.

`test_chronology.py` tests target/future-snap poisoning and truncation invariance, prior-year-only fallback, and missing first-year coverage. This does not fix historical publication timestamps: 2025 has none, and some earlier date_modified values are after kickoff. Results are exploratory, not a fully point-in-time certified backtest.

Forward protocol: freeze `forward_predictions_20261007.json`, its source snapshots and fit before the Week 5 kickoff. No fitting to future outcomes. Evaluate only captured eligible games, baseline vs experiment, with source game IDs and paired descriptive intervals after Week 5 settles. Player out-zero forecasts are separately tagged as availability, not predictive skill proof. Do not call a one-week result validated; cumulative untouched games are needed before any promotion, with interval and coverage gates. Later news captures are new immutable forecast cohorts, not rewrites of this cohort.

Commands: `python3 tools/nfl/injury_v2/evaluate.py`; `python3 tools/nfl/injury_v2/test_chronology.py`; `python3 tools/nfl/injury_v2/build_current.py`. Evaluation is reused-data diagnostics; rebuild_current writes a NEW cohort if run later and must be versioned rather than overwrite the original frozen cohort.
