# QB-context residual experiment, predeclared Oct26 2026 before fit
No book input, manual point deduction, or parameter search. Frozen historical scores-only margin-Elo/totals baseline retained. Train residual Ridge alpha10, no intercept, standardized without centering on 2020-22; diagnostics2023-24 and2025 (previously seen, not a fresh holdout). QB skill = exponentially weighted career passing+rushing EPA per dropback/carry (half-life12 appearances,100 neutral-EPA opportunity prior). QB context = announced starter skill minus team's trailing realized QB EPA rate (half-life6 games, same100 opportunity neutral prior). Difference for margin, sum for total. NonQB designation features retained from historical report/snap features (SKILL/OL/DEF absent/question/practice), never QB designation double count. Historical starter identifiers are recorded actual starters, not archived announcements; a retrospective diagnostic cannot establish deployment validity. Current starter must be verified externally. Injured-reserve inventory historically incomplete, current nonQB inputs carry coverage risk. New experiment not promoted merely because it moves a number. No guarantee of more accuracy.
